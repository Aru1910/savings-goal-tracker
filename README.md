# Savings Goal Tracker

A multi-page browser app for savings goals, a wallet, reminders and a live analytics dashboard.
Express only serves the static files. All data is saved in the browser's `localStorage`, so there is no database and no API.

## Stack

- Node.js 18+ and Express 4 (static server, security headers, graceful shutdown, `/health`)
- Tailwind CSS 3 (CLI build, class based dark mode, green theme)
- Vanilla JavaScript ES modules (no framework, no bundler)
- Inline SVG charts (no chart library)

## Getting started

Open a terminal inside the folder that contains `package.json`, then:

```bash
npm install
npm run build
npm start
```

Open http://localhost:3000

For development with live CSS rebuilds and server restarts use `npm run dev`. Change the port with `PORT=4000 npm start`.

## Pages

| Page | What you get |
| --- | --- |
| Dashboard | KPIs, savings growth, monthly deposits vs withdrawals, category split, insights and projection, things that need attention, goal progress, activity, deadlines |
| Goals | Create, edit and cancel goals, search, filters, sorting, history, move money in and out, withdraw and complete |
| Wallet | Balance, add or spend money, put money into goals, collect completed goals, full wallet history |
| Reminders | Smart reminders built from your goals plus your own one-time, weekly or monthly reminders |
| Profile | Name, income and monthly savings target, theme, browser reminders, PIN lock, backup and restore, sample data, reset |

## How money works

Money only moves through the wallet, so the books always balance.

- Everything starts empty: no goals, no wallet balance, no demo data.
- Add money to your wallet, then move it into a goal. Goals start at ₹0 and cannot be over-funded.
- Cancelling a goal refunds everything saved in it to your wallet.
- When a goal reaches 100%, use Withdraw & complete. The full amount moves to your wallet and the goal is closed. The wallet history keeps a record.
- Spend or withdraw from the wallet to take money out of the app.
- The wallet balance and each goal's saved amount are always recalculated from the transaction history, so they cannot drift apart. The Wallet page shows a live check: added − spent = wallet + in goals.
- An auto monthly plan only moves money that is really in the wallet. If the wallet is short, that month is skipped and a reminder tells you.

## Safety

- Cancelling a goal opens a confirmation dialog. A goal that holds money asks you to type its name. Cancel, complete, delete, restore and clear can be undone for a few seconds, and reset needs you to type RESET.
- Large withdrawals (half of a goal or more) ask for confirmation.
- Every input is validated and capped, imports are rebuilt from the transaction history (forged balances are ignored), and all user text is escaped before rendering.
- Optional PIN lock: salted PBKDF2 hash (150,000 iterations), attempt lockout, auto lock after 5 idle minutes. This keeps casual snoopers out. It does not encrypt the data in `localStorage`.
- Strict Content Security Policy and other security headers from `server.js`.
- Changes sync between open tabs, corrupted storage falls back to an empty state, and a failed save shows a warning.

## Data

Everything lives under the `sgt:data:v4` key in `localStorage`. Data saved by older versions is not loaded, because its money was not tracked through the wallet. Reset all data on the Profile page also removes those old keys.
Sample data can only be added while the app is empty, and the Profile page can clear it again.
Clearing browser data deletes your goals, so download a JSON backup from the Profile page now and then.
Keyboard shortcuts: `N` new goal, `/` search goals.
